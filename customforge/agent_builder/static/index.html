Gemini API Key

Stored locally in agent_builder/config/api_keys.json — used by Agent, Auto-Agent and any Gemini-backed tool step.
Get one free at aistudio.google.com/apikey. Already set it in FORGE? Restart FORGE (main.py) and it's copied over automatically.
Agent Builder runs on this by default (free, local, no quota) — Gemini above is only used as backup power if Ollama isn't running. Install Ollama, run ollama serve and ollama pull qwen2.5-coder:3b to get started. Set a node's Model field to ollama:<model> to force local only, or gemini-2.5-flash to force cloud only.
